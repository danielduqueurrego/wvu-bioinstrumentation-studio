# Source notes

The project requirements were consolidated from:

- The BMEG 420L course syllabus and teaching/not-medical-device boundary.
- The existing biomedical instrumentation board validation protocol.
- Hardware decisions supplied by the project owner.
- The approved WVU/college lockup supplied with this starter bundle.

The uploaded AD8233 datasheet is a contextual reference only. The current controlled biopotential board for this application is based on the AD8232, so AD8233-specific pin and behavior details must not be substituted into the implementation.
