# Hardware

## Supported board

The application supports one Arduino UNO R4 WiFi at a time.

## Analog inputs

Simultaneous-analog course labs can use A0–A5. A logical frame shares a sequence number and timestamp; the UNO ADC reads channels in a deterministic sequential order inside that frame.

## Controlled outputs

| Pin | Course use | Active behavior |
| --- | --- | --- |
| D4 | Blood pressure + PPG green LED | HIGH while recording only |
| D5 | Pulse-ox red LED | HIGH only during RED phase |
| D6 | Pulse-ox IR LED | HIGH only during IR phase |

All three outputs are active HIGH and are forced LOW at startup, idle, Stop, configuration failure, protocol fault, watchdog fault, and shutdown where possible. D5 and D6 are never HIGH together.

## Pulse oximetry

The fixed cycle is RED, DARK 1, IR, DARK 2. Each cycle stores raw TX and RX values for all four states. No processed optical result is generated by the application.

Teaching use only — not a medical device.
