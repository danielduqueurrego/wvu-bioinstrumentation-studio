# WVU Bioinstrumentation Studio — Student Quick Start

1. Install WVU Bioinstrumentation Studio on Windows.
2. Connect the Arduino UNO R4 WiFi by USB.
3. Open the application and confirm that Arduino is connected and Firmware is ready.
4. If a firmware update is required, open **Firmware** and choose **Restore WVU Firmware**.
5. Open **Acquisition** and choose the lab assigned by your instructor.
6. Choose a source, duration, units, and plot arrangement as instructed.
7. Start the recording. Use **Add marker** when your lab instructions call for an event marker.
8. Stop the recording and use the export control to obtain the CSV data.

Teaching use only — not a medical device. Follow BMEG 420L lab instructions and instructor safety procedures. Do not use the application for diagnosis or clinical decisions.

If the Arduino is not detected, check the USB cable and choose **Refresh Board**. If Firmware is not ready, use **Restore WVU Firmware**.
