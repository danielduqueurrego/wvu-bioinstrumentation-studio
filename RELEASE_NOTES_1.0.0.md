# WVU Bioinstrumentation Studio 1.0.0

## Included

- ECG, EMG + pressure, blood pressure + PPG, and raw four-state pulse-ox acquisition.
- Synchronized multi-channel recording with project/output folders and automatic BMEG, CSV, and metadata files.
- Counts, volts, MPXV pressure in kPa or mmHg, and supported calibration options.
- Instructor-managed course labs and bundled Arduino UNO R4 WiFi firmware recovery.
- Safe live plot reconfiguration, multi-signal legends, newest-value labels, and a synchronized 0.5–30 s display window.
- Elapsed-seconds plot axes starting at 0 for each recording. The first hardware ADC settling transient is excluded from the live display only; recorded raw samples remain authoritative and full-rate.

Teaching use only — not a medical device. Follow BMEG 420L lab instructions and instructor safety procedures. Do not use this software for diagnosis or clinical decisions.
