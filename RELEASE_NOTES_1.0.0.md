# WVU Bioinstrumentation Studio 1.0.0

## Included

- ECG acquisition.
- EMG + pressure acquisition.
- Blood pressure + PPG acquisition.
- Raw RED/DARK/IR/DARK pulse-ox acquisition.
- Project and relative output-folder organization.
- Synchronized multi-channel recording with safe plot reconfiguration, configurable plot groups, and trace visibility.
- Color-coded legends for multi-signal plots.
- A synchronized 0.5–30 s live plot window with newest-value endpoint labels.
- Counts, volts, MPXV pressure in kPa or mmHg, and supported engineering-unit calibration.
- Automatic BMEG, CSV, metadata, and marker export.
- Arduino board verification and WVU firmware restoration.
- Instructor Lab Manager for course-lab revisions.

## Requirements

- Windows x64.
- Arduino UNO R4 WiFi.

Teaching use only — not a medical device. Follow BMEG 420L lab instructions and instructor safety procedures. Do not use this software for diagnosis or clinical decisions.
